Build a complete **AI-Based Crop Recommendation System** as a full-stack web application using the **PERN stack** with a separate Python Machine Learning service.

## 1. Project Objective

Build a **Crop Recommendation System using Machine Learning**.

For my first project review, I want to demonstrate a **software-based simulation**. The user will manually enter agricultural and environmental parameters through a web dashboard. The system will send these values to the backend, where a trained **Random Forest Machine Learning model** will predict the most suitable crop.

Every prediction, along with the input parameters and timestamp, must be stored in **PostgreSQL** so that the user can view their previous prediction history.

The system should also be designed for future **hardware integration using ESP32 and sensors**. Hardware integration is NOT required now, but the API architecture should make it easy to add later.

# 6. Prediction Result

After clicking **Predict Crop**:

1. Validate the form.
2. Send the values to the Node.js backend.
3. Node.js sends the values to the Python ML service.
4. Python ML service predicts the crop.
5. Python returns the prediction.
6. Node.js stores the prediction in PostgreSQL.
7. Node.js returns the result to React.
8. React displays the predicted crop.

Example:

```text
Recommended Crop

        RICE
```

Also display the input parameters used for the prediction.

Do NOT hardcode any prediction.

Every prediction must come from the trained Random Forest model.

# 7. Node.js + Express API

Create these REST endpoints.

## Predict Crop

```text
POST /api/predict
```

Request:

```json
{
  "N": 90,
  "P": 42,
  "K": 43,
  "temperature": 25.5,
  "humidity": 80,
  "ph": 6.5,
  "rainfall": 200
}
```

The Node.js backend should:

1. Validate the input.
2. Send the seven values to the Python ML API.
3. Receive the predicted crop.
4. Insert the input values and prediction into PostgreSQL.
5. Return the result to React.

Example response:

```json
{
  "success": true,
  "predicted_crop": "rice"
}
```

* humidity
* ph
* rainfall

Sort the newest predictions first.

## Delete Prediction History

```text

```

Delete all prediction history from PostgreSQL.

```text

```

```text
Table:
prediction_history
```

```sql
CREATE TABLE prediction_history (

    humidity NUMERIC NOT NULL,
```

Use parameterized SQL queries.

Do not construct SQL queries using raw user input.

# 19. Important Requirements

* Use **PERN** for the main web application.
* Use **PostgreSQL**, not MongoDB.
* Use **React** for frontend.
* Use **Node.js + Express** for the main backend.
* Use **Python + Flask** as the separate ML service.
* Use **Random Forest Classifier** for crop prediction.
* Use exactly seven ML input features: N, P, K, temperature, humidity, ph, rainfall.
* Store every prediction in PostgreSQL.
* Provide prediction history.
* Do not use dummy prediction data.
* Do not hardcode predictions.
* Do not retrain the model during prediction.
* Keep the ML service separate from the Node.js backend.
* Use environment variables for sensitive configuration.
* Make the complete application functional.
* Keep the code simple, modular, and suitable for a student project.
* Prepare the API architecture for future ESP32/hardware integration.
